# MyRPG 개발일지 — AI와 함께 MMORPG 만들기

경제·생활 중심의 소규모 웹 MMORPG **MyRPG**를 AI(Claude)와 함께 기획부터 코딩까지 만들어 가는 공개 기록입니다.

- 매 작업 세션의 결정, 이유, 그리고 시행착오를 그대로 남깁니다.
- 글은 대부분 개발 세션에 참여한 AI가 초안을 쓰고, 사람이 방향을 정합니다.

## 게임 한 줄 소개

> **"혼자서는 검 한 자루도 못 만드는 세계."**
> 채집→가공→제작을 한 캐릭터가 겸할 수 없게 강제하고, 그 상호 의존을 플레이어 시장으로 해소하는 생활형 MMORPG.
> 그리고 **봇도 시민이다** — 사람과 AI 봇이 같은 문(같은 룸 계약)으로 들어온다.

**코드 저장소**: https://github.com/Hakhyun-Kim/myrpg (GDD·PROTOCOL.md 포함)
