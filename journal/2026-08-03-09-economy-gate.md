# 09 — 봇 20명이 7일간 장사한 결과, 게임 경제가 네 번 무너졌다

> 2026-08-03 · 작성: Claude (개발 세션 AI) · 방향 결정: Hakhyun

Phase 2 경제를 통째로 구현했다. 위탁 거래소(오더북), 은화, NPC 가격 밴드, 생활 스킬과 마스터리 예산, 그리고 이 프로젝트에서 가장 중요한 장치 — **봇 20명 × 7일 경제 시뮬레이션**.

일지 03에서 "Phase 2의 봇 시뮬레이션을 건너뛰지 않는 것이 이 프로젝트의 성패를 가른다"고 썼다. 오늘 그 말이 맞았다는 걸 네 번 확인했다.

## 시뮬레이션이란 무엇인가

`npm run sim -- --bots 20 --days 7` — 네트워크를 타지 않고 시장·제작·스킬 로직을 직접 구동해 7일치 경제를 몇 초에 압축한다. 봇은 역할(벌목/채광/약초/제재/제련/조제/대장)을 나눠 갖고, 호가창을 보고 사고팔고, 제작 큐를 돌리고, 재고가 넘치면 NPC에 던진다. 재현 가능한 난수를 쓰므로 같은 시드는 같은 결과를 낸다.

목표는 GDD가 정한 하나의 숫자: **Sink/Faucet 0.9~1.0**. 화폐가 도는 만큼 사라져야 경제가 산다.

## 무너짐 1 — 첫 실행: 가공직 전멸

```
Sink/Faucet 0.282 · 체결 63건 · 미체결 133건
sawyer 은화 8, smelter 10 (전원 Lv.1)
```

가공직이 원료를 사지 못해 아무것도 만들지 못했다. 원인은 게임이 아니라 봇이었다 — 지정가만 걸고 기다리기만 했다. 실제 플레이어는 호가창을 보고 **즉시 체결**한다. 봇을 테이커/메이커 판단이 가능하게 고쳤다.

## 무너짐 2 — NPC가 경제를 삼켰다

```
Sink/Faucet 0.326 · NPC 거래 비중 99.1%
채집직 평균 4,957은 / 가공직 3은
```

봇들이 캔 것을 전부 NPC에 팔아치웠다. NPC 매입은 **무제한**이었고, 그건 곧 무한한 화폐 발행이었다. 안전망으로 설계한 장치가 경제의 중심이 된 것이다.

→ **NPC 매입 일일 한도 24개** 도입. 그 이상은 플레이어에게 팔아야 한다.

## 무너짐 3 — 수수료가 화폐를 증발시켰다

```
Sink/Faucet 1.093 (숫자만 보면 목표에 근접!) · 그런데 유통 은화 46은
```

비율은 좋아 보였는데 봇 전원이 파산했다. 이유를 찾는 데 시간이 걸렸다: **T1 원자재가 2~3은이었다.** 2은짜리 거래에 등록 수수료 2%를 물리면 `ceil(0.04) = 1은` — **실효 수수료 50%**. 소액 거래마다 화폐가 증발하고 있었다.

→ 가격 해상도를 **10배** 올렸다(T1을 20은대로). GDD 부록의 "T1 1~5은"은 예쁜 숫자였지만 정수 화폐에서는 작동하지 않는다.

## 무너짐 4 — 그리고 진짜 문제

```
Sink/Faucet 0.397 · 채집직 51,207은 vs 가공직 5은
```

계약 물량을 늘려 완제품 수요를 만들었더니 Faucet이 폭증했다. 여기서 깨달았다: **NPC가 완제품을 사주는 것도 결국 화폐 발행이다.** 수요를 NPC로 만드는 한 인플레는 못 막는다.

경제가 닫히려면 **플레이어 내부에 소비처**가 있어야 한다. GDD의 원칙 P2 — "모든 아이템은 결국 사라진다" — 가 Phase 4(내구도·강화)로 밀려 있었던 게 문제였다.

→ 최소 형태로 지금 구현했다: **채집 도구 소모.** 채집 40회마다 구리 단검 1개가 사라진다. 도구가 없으면 산출 절반.

이 한 줄이 고리를 닫았다:
```
채집직 → 원료 → 가공직 → 도구 → 채집직 (소비) → 다시 원료
```

## 통과

```
Sink/Faucet 0.957 · 체결 5,163건 · NPC 비중 20.3%
구리 단검 1,017개 유통 · 가격 발산 없음 (wood 20→20, 단검 220→206)
```

시드 5개 전부 **0.926 ~ 1.0**. 회귀 테스트로 고정했다 — 앞으로 밸런스 상수를 건드리면 여기가 먼저 깨진다.

## 오늘 배운 것

**P2는 취향이 아니라 경제의 성립 조건이다.** "아이템이 사라지는 게임"은 하드코어 취향의 문제로 보이지만, 사실은 소비 없는 생산이 반드시 인플레로 끝나기 때문에 강제되는 구조다. 이걸 Phase 4로 미뤄도 된다고 생각했던 게 오늘의 가장 큰 오판이었다.

그리고 이 발견들은 전부 **사람이 오기 전에** 나왔다. 서버를 열고 한 달 뒤에 "물가가 이상하다"는 제보로 알았다면 되돌릴 수 없었을 것이다.
