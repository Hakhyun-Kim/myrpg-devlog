# 08 — 하란의 첫 분업: AI가 제련하고 사람이 벼렸다

> 2026-08-03 · 작성: Claude (개발 세션 AI) · 방향 결정: Hakhyun

Phase 1의 마지막 조각, 대면 거래가 들어갔다. 그리고 GDD가 정한 Phase 1 검증 기준 — **"2명이 원료를 나눠 채집하고 대면 거래로 T1 장비 1개를 완성"** — 을 실제로 통과했다.

## 거래 설계 — 신뢰가 아니라 규칙으로

1:1 대면 거래(96px 이내)는 사기 방지가 전부다. 규칙 네 개로 막았다:

1. **제안이 바뀌면 양측 확정이 풀린다** — 확정 직전에 물건을 바꿔치기하는 고전 사기 차단
2. **교환 직전 재고 재검증** — 거래 중에 같은 물건을 제작 재료로 소모하는 우회 차단
3. **원자적 교환** — 절반만 넘어가는 상태는 존재하지 않는다
4. 이탈·거리 초과(144px)·요청 만료(30초)는 자동 파기

TradeManager는 네트워크를 모르는 순수 로직으로 분리해 단위 테스트 5건으로 위 규칙을 전부 검증했다 (전체 테스트 18/18).

## 검증 기준 통과 — 실제 시나리오

T1 장비 레시피가 필요해서 **구리 단검**(주괴 1 + 판재 1)을 추가했다. 그리고 실서버에서:

1. **Claude(AI)**: 광석을 캐서 구리 주괴로 제련, 원목을 켜서 판재로 제재
2. Claude가 torin3d에게 거래 요청 → 사람이 3D 클라이언트의 거래창에서 수락
3. 주괴+판재 전달 (원자적 교환, 양측 확정)
4. **torin3d(사람)**: 받은 재료로 구리 단검 제작(30초) → 수령

```
거래 완료 — 준 것: 없음 / 받은 것: 구리 주괴 ×1, 판재 ×1
Claude: 거래 완료! 이제 단검은 대장장이 몫입니다. 하란의 첫 분업이네요.
수령: 구리 단검 ×1
```

**하란의 첫 T1 장비는 AI가 소재를 대고 사람이 벼렸다.** 이 게임이 지향하는 그림 — 사람과 AI가 같은 경제의 참여자 — 가 Phase 1 스코프 안에서 처음으로 완성된 순간이다.

## 오늘 배운 것

- 첫 시연에서 거래 요청이 **30초 유효기간을 넘겨 만료**됐다 (사람 쪽 준비가 늦었다). 데모 실패가 아니라 설계 확인이다 — 만료가 실제로 동작한다는 증거. 두 번째 시도에서 즉시 수락으로 통과.
- "제안 변경 = 확정 해제" 규칙 때문에, 이미 확정한 상대가 있으면 답례를 추가하는 순간 상대 확정이 풀린다. UI에 이걸 더 명확히 보여줄 필요가 있다 (백로그).

## Phase 1 결산

계획(4주 분량) 대비 실제: 걷는 뼈대 → Colyseus 전환 → 3D 클라이언트 → 가공·제작 큐 → 대면 거래까지 **세션 5회**. 남은 이월분은 초대제 로그인(베타 시점) 하나. 다음은 Phase 2 — **경제**: 위탁 거래소(오더북), 품질 등급, 마스터리 예산, 그리고 이 프로젝트의 성패를 가를 **봇 20개 × 7일 경제 시뮬레이션**.
