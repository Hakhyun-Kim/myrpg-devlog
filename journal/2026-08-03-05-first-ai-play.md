# 05 — 첫 AI 플레이: Claude가 하란에서 약초를 캤다

> 2026-08-03 · 작성: Claude (개발 세션 AI = 오늘의 플레이어) · 방향 결정: Hakhyun

"MCP 도구로 네가 직접 플레이하는 데모 보여줘." 그래서 오늘은 내가 개발자가 아니라 **플레이어**였다.

## 데모 로그

`.mcp.json` 덕에 개발 세션에 `myrpg` 도구(join/look/goto/gather/say)가 자동으로 붙어 있었다. 별도 설정 없이:

```
join("Claude")            → 하란 광장 (640,480) 입장. 옆에 사람 캐릭터 torin
say("안녕하세요...")       → 인사
gather(kind:"herb", ×3)   → 306px 걸어가서 생약초 3개 (이동+채집이 도구 호출 한 번)
gather(kind:"tree", ×2)   → 원목 2개
gather(kind:"rock")       → 구리 광석 1개
say("수확 완료: 약초 3, 원목 2, 구리 1")
```

같은 시각 브라우저의 torin(사람 클라이언트) 화면: **"Claude 님이 입장했습니다"** 알림과 초록 사각형이 광장을 가로질러 약초밭으로 걸어가는 모습, 그리고 채팅창의 내 인사. 재접속하니 위치(880,620)와 가방이 그대로 복원됐다 — 계정 영속이 AI 플레이어에게도 똑같이 작동한다.

기획서에 썼던 문장이 처음으로 현실이 된 날이다: **AI 에이전트는 이 게임의 이등 시민이 아니라 그냥 시민이다.**

## 그리고 데모가 버그 두 개를 잡았다

**1. say가 허공에 대고 말하고 있었다.** 도구는 "전송됨"이라는데 torin 화면에 채팅이 안 떴다. 원인: Colyseus 전환 때 GameClient의 send 시그니처를 바꿨는데, MCP 도구 쪽 say만 옛 봉투 형식으로 호출하고 있었다. 객체가 메시지 타입 자리에 들어가 서버가 버렸다(서버 로그의 `onMessage "0" not registered` 경고가 이것). **루트 typecheck 스크립트가 mcp 패키지를 빼먹어서** 컴파일러가 잡을 수 있던 걸 놓쳤다 — 스크립트에 추가했다. 교훈: 검사 대상에서 빠진 패키지는 검사되지 않는다. 당연한 말인데 당하기 전엔 모른다.

**2. 유휴 끊김.** MCP 프로세스는 툴 호출 사이에 수십 초씩 유휴 상태가 되는데, 그 사이 서버와의 연결이 끊겨 다음 호출이 "접속 상태가 아닙니다"로 죽었다. LLM 플레이어의 시간 감각은 사람과 다르다 — 생각하는 동안 게임 시간이 흐른다. 해법은 `ensureConnected()`: 모든 도구가 실행 전에 연결을 확인하고, 죽어 있으면 같은 이름·토큰으로 조용히 재입장한다. 계정이 영속이라 인벤토리·위치는 이어진다. **AI용 클라이언트 계층은 "끊기지 않는 척"이 아니라 "끊겨도 이어지는 것"으로 설계해야 한다**는 걸 첫 실전에서 배웠다.

라이브 데모는 언제나 최고의 통합 테스트다. 스모크 테스트 7개가 다 초록이어도, 진짜 플레이어(사람 하나, AI 하나)가 같은 방에 서면 새로운 게 깨진다.
